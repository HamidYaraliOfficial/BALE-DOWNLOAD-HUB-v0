# راهنمای کاربر (خلاصه)

> نسخهٔ کامل و مصور: `BALE_DOWNLOAD_HUB_GUIDE_FA.pdf` · راهنمای داخل برنامه: «مرکز راهنما».

## ۱. نصب
1. Python 3.11+ (از python.org، با تیک *Add to PATH*).
2. `BALE_DOWNLOAD_HUB.zip` را استخراج و `run.bat` را اجرا کنید (یا `run.ps1`). بار اول وابستگی‌ها نصب می‌شوند.
3. اختیاری: `ffmpeg.exe` و `ffprobe.exe` را در پوشهٔ `bin` بگذارید (برای مدت/رزولوشن ویدئو و Thumbnail).

## ۲. ساخت ربات، توکن، کانال
* ربات را با ربات رسمی **@botfather** در بله بسازید (مراحل: `docs.bale.ai`) و **توکن** را بگیرید.
* توکن را فقط در برنامه وارد کنید؛ در Credential Manager ذخیره می‌شود. هرگز منتشرش نکنید.
* یک کانال بسازید (برای سادگی عمومی با `@username`)، ربات را **ادمین با اجازهٔ ارسال پیام** کنید.
* شناسهٔ مدیران: از هر فرد بخواهید به ربات پیام بدهد؛ ربات شناسهٔ عددی‌اش را در پاسخ می‌نویسد.

## ۳. راه‌اندازی
Setup Wizard (۱۰ مرحله) در اولین اجرا: زبان ← توکن (آزمایش) ← اتصال ← کانال ← بررسی دسترسی (پیام آزمایشی که حذف می‌شود) ← مدیران ← پوشهٔ موقت ← محدودیت‌ها ← پاک‌سازی ← فعال‌سازی. همهٔ ورودی‌ها مثال، راهنما (؟)، اعتبارسنجی و لینک راهنمای رسمی دارند و با بستن برنامه حفظ می‌شوند.

## ۴. کار روزمره
* **دانلودها ← افزودن لینک ←** تحلیل ← تأیید. دکمه‌های توقف/ادامه/لغو/تلاش مجدد/اولویت/پیش‌نمایش.
* **ربات**: لینک بفرستید؛ `/status /queue /cancel /pause /resume`.
* **پیش‌نمایش**: اگر «انتشار خودکار» خاموش باشد، هر فایل منتظر تأیید می‌ماند.
* **زمان‌بندی**: در پنجرهٔ افزودن لینک (برنامه باید باز باشد).
* **چند کانال / مسیریابی نوع فایل**: بخش کانال‌ها.
* **API داخلی** (اختیاری): تنظیمات ← ربات؛ `docs/API.md`.

## ۵. پاک‌سازی و حریم خصوصی
پس از انتشار (و پس از شکست/لغو) پوشهٔ موقت همان کار کامل حذف می‌شود؛ گزارش در «پایش و گزارش‌ها ← پاک‌سازی». حالت حریم خصوصی URL و نام فایل را هم از تاریخچه پاک می‌کند. حذف ≠ پاک‌سازی امن.

## ۶. رفع خطا
| نشانه | کار |
|---|---|
| توکن رد شد | توکن جدید از BotFather |
| Forbidden / not a member | ربات را ادمین کانال با اجازهٔ ارسال کنید |
| آدرس خصوصی مسدود شد | عمدی است (SSRF) |
| حجم بیش از سقف | سقف را تغییر دهید یا «تقسیم فایل بزرگ» |
| فضای دیسک کم | فضا آزاد کنید؛ «ادامهٔ صف» |
| «قبلاً در حال اجراست» | پنجرهٔ دیگر را ببندید یا `app.lock` را حذف کنید |

لاگ‌ها: `%APPDATA%\BaleDownloadHub\logs` (ماسک‌شده).
